Welcome to PhineX Docs

PhineX started on November 13, 2025, founded by @A.Elgohary on a simple idea: building software alone takes months, building it with a team of senior developers takes weeks. Instead of developers working in isolation, PhineX runs a community-first model — senior programmers collaborate, mentor newcomers through X-Academy, and split profits fairly across every shipped project.

Project

🕵️ ElJasus

JavaScript Firebase Tailwind CSS Live

ElJasus is a real-time multiplayer party game for friends and family — a mix of acting and detective work built entirely on JavaScript and Firebase, so rounds play out live with no page refresh needed.

Each round, the game randomly assigns one player as the Spy; everyone else is an Innocent. The host picks a category, and the system randomly chooses a secret word from it — only the Innocents get to see it. Nobody, Spy or Innocent, knows who holds which role.

Players take turns asking each other questions about the secret word without saying it outright. Innocents answer naturally since they know the word; the Spy has to bluff convincingly while trying to piece together what the word is from everyone else's answers. After enough rounds of discussion, the group votes on who they think the Spy is.

If the group's vote lands on the real Spy, the Spy gets one last chance — guess the secret word correctly and the Spy still wins despite being caught. If the vote lands on an innocent player instead, the Spy wins outright.

🛡️ JMS — El Jasus Moderation System

JMS is the chat filter running behind every ElJasus room. It scans messages for profanity, harassment, spam, and threats, and escalates through five severity levels — from a quiet warning up to an instant, non-appealable ban for genuine threats.

Lvl 1 · Minor Lvl 2 · Harassment Lvl 3 · Severe profanity Lvl 4 · Hate speech Lvl 5 · Threats (permanent)

The current version (v4.0) rebuilt the detection engine around whole-word matching instead of raw substring scanning, which fixes a common false-positive class — ordinary words like "hello" or "class" no longer get flagged just because they contain "hell" or "ass". It also removed rules that used to flag religious symbols, pride/trans flags, and neutral identity words (like "gay" or "autistic") as violations — only genuine slurs and harassment are caught now. Deliberately obfuscated text (spaced-out letters, symbol substitutions like "id10t") is still caught by a dedicated evasion check.

Multi-language aware
JMS reads Arabic, English, and Franco-Arabic (Arabic written with Latin letters and numbers, e.g. "5ara") in the same pass, so switching languages mid-message doesn't slip past it.

Troubleshooting

ElJasus & JMS

Common problems in-game, and what they usually mean.

My message didn't send, or I got warned unexpectedly
  • A warning means JMS flagged something in your message as profanity, harassment, or spam — the ban screen or toast tells you which level. Re-read your message for anything that could match, including l33tspeak spellings.
  • Check your connection — a message that looks like it didn't send may just be a slow Firebase round-trip. Wait a few seconds before resending.
  • If you're confident the message was clean, it's worth reporting — JMS v4.0 fixed a lot of false positives, but new dialect-specific ones can still slip through.
I think I was banned by mistake
  • The ban screen shows the level and duration — Levels 1–4 are temporary (hours to weeks); Level 5 (direct threats) is permanent and isn't lifted.
  • Repeat offenses shorten the warning threshold before the next ban, so a second flag can escalate faster than the first.
  • For temporary bans you believe were wrong, reach out on Discord with the room code and roughly when it happened — the team can check the flagged message.
Round got stuck, or a player disconnected
  • Refresh the page — ElJasus syncs game state through Firebase, so rejoining the same room code puts you right back in.
  • If the whole room is frozen, ask the host to restart the round — only the host can force a new round.
  • Still stuck after a refresh and a new round? It's likely a real bug — please report it (see Get Help below).
Troubleshooting

X-Code

My files or code disappeared after refreshing
  • Make sure you're not in private/incognito mode — local storage is wiped when that window closes.
  • Check your browser hasn't blocked site storage/cookies for X-Code specifically (site settings → permissions).
  • If autosave genuinely dropped your work, report it with your browser and OS — that's the fastest way to trace it.
The AI assistant isn't responding
  • Check your internet connection, then retry — free AI access can be rate-limited under heavy load.
  • Refresh the page once if it's been stuck for more than a minute.
  • Still nothing? It's likely a provider-side outage rather than your setup — try again shortly.
Editor feels laggy on large files
  • Close unused tabs in the file explorer — each open tab keeps state in memory.
  • Lower the workspace zoom/ratio setting — heavier visual themes cost more on large documents.
  • Split very large files where you can; the editor is tuned for typical web-project file sizes.
Troubleshooting

SolveX

Photo upload isn't solving correctly
  • Make sure the shot is well-lit, in focus, and cropped to just the problem — stray handwriting or glare is the most common cause of misreads.
  • Straighten the photo if it was taken at an angle; skewed text is harder to parse than upside-down text.
  • For handwritten problems, write digits and symbols (especially ×, ÷, √) clearly and separated.
The steps skip ahead, or the final answer looks wrong
  • Double-check how you typed the problem — ambiguous notation (missing parentheses, unclear exponents) is the usual culprit.
  • Try rephrasing or retyping the problem instead of re-uploading the same photo.
  • If it's consistently wrong for a specific problem type, that's worth reporting as an edge case.
Arabic input isn't being recognized
  • Confirm the language toggle is actually set to Arabic before submitting.
  • Avoid mixing Arabic and English digits/symbols in the same expression where possible.
Troubleshooting

X-Academy

The pretest or developer test froze, or won't submit
  • Use an up-to-date Chrome, Edge, or Firefox — older browser versions are the most common cause of a stuck test screen.
  • Stay on a stable connection for the whole test; don't refresh mid-test, since that can reset your progress and timer.
  • If it genuinely froze partway through, note the question number and message the team on Discord rather than retrying repeatedly.
I haven't heard back about my Developer Track results
  • Results and next steps are usually shared through Discord, not email — make sure you've joined the server and DMs are open.
  • Give it a few days during busy assessment periods before following up.
Troubleshooting

Account & Access

My redeem code isn't working
  • Copy the code exactly — extra spaces or a stray character at the start/end is the most common issue.
  • Codes are one-time use; if someone else already redeemed it, it won't work a second time.
  • Expired or already-used codes need to be reissued — ask in Discord with where you originally got the code.
I can't log in, or forgot my password
  • Use Forgot Password on the sign-in page to get a reset link by email.
  • If you originally signed up with Google, use the Google button instead of typing a password — those accounts don't have one.
  • Check spam/junk folders for the reset email before requesting another one.
Verification email never arrived
  • Check spam/promotions folders first — this is by far the most common cause.
  • Confirm the email address was typed correctly during sign-up before requesting a resend.
